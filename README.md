PrettyVisuals

Visual mod for Minecraft: pets, cosmetics, capes and HUD effects.
Features
🐾 Pets: companions that follow you around
🎩 Cosmetics: decorations and accessories for your character
🧣 Capes: custom capes
✨ HUD effects: visual effects on the interface
🚀 More features and performance optimization coming soon

Fabric API

Installation
Install Fabric Loader for Minecraft 1.21.11.
Download Fabric API for 1.21.11 and put it into the mods folder.
Download Pretty_Visual_1_4_0.jar from this repository and put it into the mods folder.
Launch the game.
The mods folder location:
Windows: %appdata%\.minecraft\mods
Linux: ~/.minecraft/mods
macOS: ~/Library/Application Support/minecraft/mods
